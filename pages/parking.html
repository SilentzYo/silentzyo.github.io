Parking

Projects Resume GitHub

Parking finds open spots in a parking lot from a camera. You mark where the spots are once by clicking the corners of each row, and it splits the row into individual spots. A YOLO model then detects the cars, and any spot without a car in it counts as free.

It runs on a photo, a video, a webcam, or an RTSP stream, and can write each spot's status to a JSON file. For lots where the cars are small in the frame, it tiles the image so the detector can still pick them out.
