Schoology Post Remover

Projects GitHub Contact

A Manifest V3 Chrome extension that cleans up the Schoology Recent Activity feed. Clicking Remove in the popup injects a script into the active tab with the Chrome scripting API. The script expands the feed with the "More" button, removes posts from a list of accounts I didn't need updates from, and scrolls back to the top.
